# 🏥 MediDiagnost - Медицинский диагностический сайт

Современный веб-сайт для диагностики болезней по симптомам с крутым UI/UX и интеграцией с OpenAI для анализа фото и описаний.

## 🚀 Особенности

✅ **20+ заболеваний** в базе данных
✅ **Интеллектуальный поиск** - система анализирует симптомы и предлагает возможные диагнозы
✅ **Анализ с помощью ИИ OpenAI** 🤖:
   - Загрузка фотографий области поражения
   - Описание симптомов и жалоб
   - GPT-4 Turbo анализирует и извлекает симптомы
   - Автоматический поиск подходящих диагнозов

✅ **Автодополнение** - при введении симптомов предлагаются варианты
✅ **Подробная информация** - описание, причины, симптомы, лечение и профилактика
✅ **Адаптивный дизайн** - работает на всех устройствах
✅ **Гладкие анимации** - современный интерфейс
✅ **Процент совпадения** - система показывает, насколько симптомы совпадают с диагнозом
✅ **Два режима работы:**
   - 📝 По симптомам - традиционный ввод симптомов
   - 🤖 Анализ ИИ - загрузка фото и описание для ИИ анализа

## 🔑 Как установить и использовать

### 1. API ключ уже встроен! ✅
API ключ OpenAI уже настроен в приложении, не требуется никаких действий.

### 2. Используйте функции ИИ
- Перейдите на вкладку "🤖 Анализ ИИ"
- Загрузите фото (или перетащите сюда)
- Опишите симптомы
- Нажмите "Анализ с помощью ИИ"

## 📋 Как использовать

### Вариант 1: Традиционный поиск по симптомам
1. **Откройте** файл `index.html` в браузере
2. **Введите симптомы** - начните писать симптом в поле поиска
3. **Выберите из подсказок** - система предложит варианты
4. **Добавьте несколько симптомов** - кликните на кнопку "Поиск" или нажмите Enter
5. **Просмотрите результаты** - система покажет возможные диагнозы с процентом совпадения
6. **Узнайте подробности** - нажмите "Подробнее" для полной информации о болезни

### Вариант 2: Анализ с помощью ИИ
1. **Перейдите на вкладку "🤖 Анализ ИИ"**
2. **Загрузите фото** - фото области с симптомами (сыпь, ранка, и т.д.)
   - Можно перетащить туда файл с компьютера
   - Можно выбрать через "Выберите фото"
3. **Опишите симптомы** - напишите подробное описание (боль, температура, когда началось, и т.д.)
4. **Нажмите "Анализ с помощью ИИ"** - система отправит на анализ в OpenAI
5. **Получите результаты** - ИИ автоматически найдёт совпадающие диагнозы
